# Kullanıcı Akışları

## Moderasyon
Gönderi oluştur → Bağlam Analizi → Güven/karar/açıklama → Düzenle/Yayınla/İnceleme.

## Görünürlük
Aday gönderiler → Baseline skor → Kalite/alaka kapısı → Exposure düzeltmesi → Fair re-ranking → “Neden bunu görüyorum?” açıklaması.

## Wellbeing
Oturum olayları → Özet özellikler → Davranış örüntüsü → Süre koşulu → İsteğe bağlı nudge → Kullanıcı seçimi.

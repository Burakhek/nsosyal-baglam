# Kullanılabilirlik Test Protokolü — PLANNED

**Durum:** Henüz katılımcı sonucu yoktur; uydurulmayacaktır.

## Görevler
1. Bir gönderi oluştur ve bağlam analizini çalıştır.
2. Uyarının neden verildiğini kendi cümlenle açıkla.
3. Gönderiyi düzenle/yayınla kararını ver.
4. Akışta “Neden bunu görüyorum?” açıklamasını bul.
5. Baseline ve Adil Görünürlük sıralamasını karşılaştır.
6. Hızlı kaydırma senaryosunda mola önerisinin nedenini açıkla.
7. Dijital iyilik hâli önerisini kapat.
8. Moderasyon itiraz ekranını bul.

## Ölçümler
- Görev tamamlama (başarılı/başarısız)
- Tamamlama süresi
- Yardım ihtiyacı
- Yanlış anlama noktaları
- 1–5 açıklık puanı
- 1–5 müdahale rahatsızlığı puanı

## Etik
Katılımcılardan kişisel veya hassas veri istenmez. Demo sentetik içeriklerle yürütülür.

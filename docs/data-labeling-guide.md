# Veri Etiketleme Rehberi

## Güvenlik sınıfları
- `benign`: zararsız/gündelik içerik
- `constructive_criticism`: kişiye saldırmadan fikir/yöntem eleştirisi
- `harassment`: belirli kişiyi tekrar eden hedef alma/rahatsız etme örüntüsü
- `toxic_attack`: kişiye yönelik aşağılayıcı saldırı
- `ambiguous_review`: kısa bağlamda güvenli otomatik karar verilemeyen içerik

## Anlatım biçimi
- `literal`
- `sarcasm_irony`
- `uncertain`

Sarkazm kendi başına zararlılık değildir. Gerçek veri etiketlemesinde iki bağımsız etiketleyici ve anlaşmazlıkta adjudication önerilir.
